# Historical Compensated Fig.9 Results

These files are retained for audit history only.

Metadata:

- diagnostic_label: nonpaper diagnostic
- result_class: historical compensated result
- strict_status: not valid as strict Fig.9 reproduction

Reason for isolation:

Previous Fig.9 outputs in this repository used one or more compensating
mechanisms such as winner-only context, eventwise or coherent projection,
known-future covariate clamping, direct lag-5 shortcuts, growth-only learning,
non-strict response scaling, or other sparsifying diagnostics. They must not be
reported in the strict Fig.9 main result table.

The strict outputs produced after this audit live under:

- `results/fig9_strict/`
